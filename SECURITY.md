# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue**.

Instead, report it privately through one of these channels:

- [GitHub Private Vulnerability Reporting](https://github.com/MathiasPaulenko/dev-command-center/security/advisories/new) (preferred)
- Contact the maintainer via the profile on [GitHub](https://github.com/MathiasPaulenko)

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The version/commit affected

You can expect an initial response within a few days. If the report is confirmed, a fix will be released as soon as possible and credited appropriately.

## Scope

DevCommandCenter executes user-configured shell commands by design — that is its core feature. Please note this when evaluating what constitutes a vulnerability versus intended behavior.
